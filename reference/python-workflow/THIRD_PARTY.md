# Third-party components

This source package does not include model weights or third-party package code.

The reference environment installs:

- PyTorch
- NumPy
- Pillow
- SciPy
- OpenCV
- `simple-lama-inpainting`
- the upstream `big-lama.pt` model downloaded by `simple-lama-inpainting`

Before public or commercial deployment, review and comply with each upstream
package and model license. Keep their notices with any redistributed binaries,
containers, or model weights. The repository MIT license applies only to the
original workflow code and documentation here.
